# gBizINFO 企業情報収集ツール

[gBizINFO](https://info.gbiz.go.jp/)（経済産業省が提供する法人情報の公式データベース）の
REST API から、条件に合う企業の情報を取得して CSV / Excel に出力するコマンドラインツールです。

デフォルトの絞り込み条件は以下の通りです（コマンドライン引数で変更可能）。

- 従業員数: 20人以上50人以下
- 都道府県: 埼玉県 または 千葉県

## 取得できる項目

| 項目 | gBizINFO APIでの取得可否 |
| --- | --- |
| 法人名 | ○ |
| 都道府県 | △ (所在地の文字列から自動抽出) |
| 市区町村 | △ (所在地の文字列から自動抽出) |
| 住所 | △ (所在地の文字列から都道府県・市区町村を除いた残り) |
| 従業員数 | ○ |
| 事業概要 | △ (登録されている法人のみ) |
| 企業URL | △ (登録されている法人のみ) |
| 電話番号 | × (gBizINFO APIには電話番号の項目が存在しないため、常に空欄) |

gBizINFO は届出・認定・補助金・調達情報などをもとにしたデータベースのため、
**事業概要・企業URLなどは登録がある法人のみ値が入ります**（ユーザー様のご認識の通り、
すべての項目が埋まるわけではありません）。また、そもそもAPIのレスポンスに
電話番号の項目が存在しないため、電話番号は本ツールでは取得できません
（列だけ用意し、空欄で出力します）。

住所については、APIが「本社所在地」を1つの文字列（例:
`埼玉県さいたま市大宮区桜木町1-1-1`）でしか返さないため、本ツール側で
都道府県名・市区町村名を正規表現で分割しています。政令指定都市（さいたま市・
千葉市など）は区名まで含めて「市区町村」欄に出力します。まれに住所の書式が
特殊な法人では分割がずれる可能性があるため、正確な住所が必要な場合は
「住所」列の元データ（`都道府県+市区町村+住所` を連結したもの）と突き合わせて
ご確認ください。

## セットアップ

### 1. APIトークンの取得

gBizINFO の利用にはAPIトークンの申請が必要です（無料）。

1. https://info.gbiz.go.jp/ の「REST APIを利用する」から利用申請を行う
2. 申請後、登録したメールアドレスにトークン確認用のURLが届く
3. URLからトークンを確認する

### 2. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 3. トークンの設定

```bash
export GBIZINFO_API_TOKEN="取得したトークン"
```

（`--token` オプションで直接指定することも可能です）

## 使い方

デフォルト条件（埼玉県・千葉県、従業員数20〜50人）でCSVに出力:

```bash
python gbizinfo_collector.py --output companies.csv
```

Excel形式で出力:

```bash
python gbizinfo_collector.py --output companies.xlsx
```

条件を変更する例（東京都・神奈川県、従業員数10〜30人）:

```bash
python gbizinfo_collector.py \
  --prefectures 東京都 神奈川県 \
  --employee-min 10 \
  --employee-max 30 \
  --output companies.csv
```

### オプション一覧

| オプション | 説明 | デフォルト |
| --- | --- | --- |
| `--prefectures` | 対象の都道府県（都道府県名 または JIS X0401コード、複数指定可） | `埼玉県 千葉県` |
| `--employee-min` | 従業員数の下限 | `20` |
| `--employee-max` | 従業員数の上限 | `50` |
| `--output` | 出力ファイルパス（拡張子 `.csv` / `.xlsx`） | `gbizinfo_companies.csv` |
| `--token` | APIトークン（未指定時は環境変数 `GBIZINFO_API_TOKEN` を使用） | - |

## テスト

住所分割ロジックなど、API呼び出しを伴わない部分の単体テストを用意しています。

```bash
python -m unittest discover -s tests
```

## 注意事項

- gBizINFO APIの1ページあたりの上限は5,000件、取得可能なページ数は最大10ページ
  （1都道府県あたり最大50,000件）です。想定条件では十分な件数ですが、
  それ以上ヒットする場合は `--employee-min` / `--employee-max` 等で
  条件を絞り込んでください。
- APIへの過度なアクセスを避けるため、ページ取得ごとに待機時間を入れています。
- 出力されるCSVはExcelでの文字化けを避けるため UTF-8 (BOM付き) で保存されます。
