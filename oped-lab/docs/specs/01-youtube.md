# 01 YouTube系のOPとED

## ジャンルの前提

- OP は3〜20秒が一般的で、10秒前後を勧める案内が多い。長いほど本編前に離脱されやすい。
- ED は YouTube の「終了画面」機能の台紙として作る。終了画面は動画の最後の5〜20秒に、最大4つの要素(動画、再生リスト、チャンネル登録、リンク)を重ねられる。動画全体が25秒以上あることが条件。
- どちらも 1920×1080、16:9。

出典は末尾にまとめています。

## サンプル仕様

5本とも [reactvideoeditor/remotion-templates](https://github.com/reactvideoeditor/remotion-templates)(MIT)のコードから読み取った値です(コード実測、30fps 換算)。

### Y1 タイトル+下線(`cinematic-title-intro.tsx`)

| 時刻 | 要素 | 動き |
|---|---|---|
| f0–40 | タイトル(64px、太字、白、字間 0.05em) | 下 50px から上がる。spring(damping 14, mass 0.8)、40フレームで完了 |
| f0–30 | タイトルの不透明度 | 0→1。spring、30フレーム |
| f20–50 | 下線(高さ 4px、最大幅 320px、2色グラデーション) | 幅 0→100%、直線補間 |
| f40–60 | サブタイトル(24px、細字、字間 0.1em) | 不透明度 0→1 |

- 構成: 動きは2秒で完了し、以後は静止。要素は3つだけで、登場をそれぞれ20フレームずつずらす。
- 配色: 暗い紺のグラデーション地に白文字。
- 再現判定: ◎

### Y2 上下合わせタイトル(`title-split.tsx`)

| 時刻 | 要素 | 動き |
|---|---|---|
| f0〜 | 上段の語(80px) | 上 120px から中央へ。spring(damping 14, stiffness 80) |
| f0〜 | 下段の語(80px) | 下 120px から中央へ。同じばね |
| f0–20 | 2語が合う進み具合 | 0→1(中央の光の強さに使用) |
| 常時 | 文字の光彩 | sin(frame × 0.1) で 0.3〜0.8 を往復。周期は約63フレーム |

- 構成: 2語を逆方向から同時に入れて中央で合わせる。合った後は光の脈動だけが続く。
- 再現判定: ◎

### Y3 カウントダウン(`countdown-intro.tsx`)

| 時刻 | 要素 | 動き |
|---|---|---|
| f0–90 | 数字 3、2、1(64px) | 1秒ごとに切り替え |
| f0–90 | 円の輪(半径 70) | 1秒かけて1周ぶん線が消え、毎秒やり直す |
| f90〜 | 「GO!」(56px) | 拡大して登場。spring(damping 8, stiffness 100)で行き過ぎて戻る |
| f90–95 | 「GO!」の不透明度 | 0→1(5フレーム) |

- 構成: 3秒の待ち時間で期待を作り、4秒目に一番強い動きを置く。
- 再現判定: ◎

### Y4 終了カード(`end-card.tsx`)

| 時刻 | 要素 | 動き |
|---|---|---|
| f0–35 | カード全体 | 拡大 0.8→1。spring(damping 12, mass 0.6) |
| f0–30 | カードの不透明度 | 0→1 |
| 常時 | 枠線と影の光 | sin(frame × 0.08) で 0.3〜0.7。周期は約79フレーム |
| f20–45 | 登録ボタン | 不透明度 0→1 |
| f30–55 | 丸いアイコン4つ | 不透明度 0→1 |

- 構成: 見出し、ボタン、アイコンの順に10フレームずつずらして出す。その後は枠の光だけが動く。
- 注意: このテンプレートは終了画面の要素を置く場所を空けていない。実際の ED では動画枠と登録枠の余白が必要。
- 再現判定: ◎

### Y5 登録の呼びかけ(`subscribe-reminder.tsx`)

| 時刻 | 要素 | 動き |
|---|---|---|
| f10〜 | 登録バー | 下 100px からせり上がる。spring(damping 14, stiffness 100) |
| 常時 | ベルのアイコン | sin(frame × 0.15) で 1〜1.15倍に脈動。周期は約42フレーム |

- 構成: 本編に重ねる小さな帯。登場後は1か所だけを脈動させて視線を集める。
- 再現判定: ◎

## 共通パターン

1. 動きは最初の1〜2秒に集め、残りは小さな脈動だけにする。
2. 要素は3〜4個。登場を10〜20フレームずつずらす。
3. 登場はばね(damping 12〜14)。ポップにしたいときは damping 8〜9 で行き過ぎを作る。
4. 待機中の動きは sin で作る。係数 0.08〜0.15、振れ幅は 15% 以内。
5. 暗い地に白文字と2色のアクセント、という配色が多い。

## 試作仕様 YT-OP(6秒、180フレーム)

実装: `src/compositions/youtube/YouTubeOP.tsx`

サンプルとの違い: 5本とも暗い配色だったので、差別化のため紙色の地に3色の原色を置く明るい配色にした。チャンネル名「つくる実験室」は仮の名前。

| 時刻 | 要素 | 動き | 元にしたサンプル |
|---|---|---|---|
| f0–28 | 斜めの色帯3本(朱、青、黄) | 4フレームずつずれて左から右へ抜ける。inOut | 新規 |
| f6–22 | 紙色の地 | 左から右へ現れる | 新規 |
| f14〜 | マーク(朱の円にプラス記号) | 拡大して登場。spring(damping 9, stiffness 140, mass 0.7) | Y3 の行き過ぎるばね |
| f18–44 | プラス記号 | 半回転して止まる。out | 新規 |
| f24–44 | マーク | 上へ 330px 移動し、半分に縮む。タイトルが入る前に場所を空ける。inOut | 新規 |
| f38〜 / f42〜 | タイトル上段 / 下段(190px) | 上から / 下から中央へ。spring(damping 13, stiffness 110) | Y2 |
| f62–84 | 下線(幅 760px) | 左から伸びる。out | Y1 |
| f70〜 | タグライン(46px) | 1フレームに 0.6 文字ずつタイプ表示 | 新規 |
| f88、f103、f118 | 紙吹雪26個 | 3回に分けて中心から弾ける。位置は乱数の種で固定 | 新規 |
| f60–150 | 全体 | 1→1.05倍にゆっくり寄る | 新規 |
| f150–176 | 全体 | 円形に閉じる(アイリスアウト)。in | 新規 |

差し替えできる項目: タイトル上段と下段、タグライン、5色。

次に検討すること:

- 効果音(ワイプ、ポップ、タイプ音)を入れる。
- 6秒は標準的な長さ。3秒の短縮版(マークとタイトルだけ)も用意する。
- 縦型(1080×1920)のショート用レイアウト。

## 試作仕様 YT-ED(20秒、600フレーム)

実装: `src/compositions/youtube/YouTubeED.tsx`

終了画面の要素を重ねる場所を空けた台紙。`showGuides` を false にすると枠内の案内文字が消える。

要素の枠(1920×1080 基準、`END_SCREEN_SLOTS` で定義):

| 枠 | 位置と大きさ |
|---|---|
| 動画枠1 | 左上 (1080, 110)、700×394(16:9) |
| 動画枠2 | 左上 (1080, 574)、700×394(16:9) |
| 登録の円 | 中心 (290, 740)、半径 130 |

| 時刻 | 要素 | 動き | 元にしたサンプル |
|---|---|---|---|
| f0–20 | 朱の幕 | 上へ抜ける。inOut | 新規 |
| f16–56、f24–64 | 動画枠の輪郭 | 線で描く(40フレーム)。inOut | 03 の B1 |
| f36〜 | 動画枠の地と色のずらし影 | 不透明度 0→1 | 新規 |
| f26–40 | 英字の小見出し | 不透明度 0→1 | Y1 |
| f30〜、f40〜 | お礼の見出し2行(88px) | 1文字ずつ下からせり上がる。2フレーム間隔、1文字18フレーム | 新規 |
| f58–84 | 下線 | 左から伸びる | Y1 |
| f70〜 | 登録の円 | 拡大して登場。spring(damping 9, stiffness 130, mass 0.7) | Y4 |
| f100〜 | 登録の円 | sin(frame × 0.09) で ±3.5% 脈動。2秒ごとに輪が広がる | Y4、Y5 |
| f96–116 | 矢印とラベル | 右から 40px 寄って現れる | 新規 |
| f90〜 | 下端のクレジット帯 | 下からせり上がり、1フレーム 3px で左へ流れる | 03 の補足(クレジットロール) |
| f570–598 | 全体 | フェードアウト | 新規 |

差し替えできる項目: お礼の文、チャンネル名、登録ラベル、枠のラベル2つ、クレジットの文、案内表示の有無、5色。

次に検討すること:

- YouTube Studio で終了画面の要素を置き、枠とのずれを確認して `END_SCREEN_SLOTS` を調整する。要素の大きさは Studio 側で変えられるが、位置と大きさの下限があるため実機で合わせる。
- BGM を入れ、登録の円の脈動を拍に合わせる(`makeGrid` を使う)。
- 動画枠を1つにした版、縦型の版。
