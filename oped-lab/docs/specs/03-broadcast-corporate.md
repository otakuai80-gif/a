# 03 番組・企業系のオープナー

## ジャンルの前提

- 会社紹介、セミナー、番組の冒頭に置く、ロゴと名前を見せる短い映像。3〜10秒が中心。
- 動きは少なく、ロゴの出し方ひとつで印象を作る。色数も少ない。
- 同じ部品(名前のテロップ、章の見出し)を本編でも使い回す。

## サンプル仕様

5本とも [reactvideoeditor/remotion-templates](https://github.com/reactvideoeditor/remotion-templates)(MIT)のコードから読み取った値です(コード実測、30fps 換算)。

### B1 ロゴの線描き(`logo-stroke-draw.tsx`)

| 時刻 | 要素 | 動き |
|---|---|---|
| f0–36 | 外側の図形(六角形)の輪郭 | 線が1周ぶん描かれる。直線補間 |
| f12–48 | 内側の図形(三角形)の輪郭 | 12フレーム遅れて同じように描かれる |
| f48–66 | 図形の塗り | 不透明度 0→1 |
| f60–75 | 社名(約29px) | 不透明度 0→1 |

- 構成: 外、内、塗り、名前の順。前の動きが終わる少し前に次を始める。全体で2.5秒。
- 再現判定: ◎(線の長さは `@remotion/paths` の `evolvePath` で扱える)

### B2 ロゴの左右展開(`logo-split-reveal.tsx`)

| 時刻 | 要素 | 動き |
|---|---|---|
| f10–45 | ロゴの左半分と右半分 | 中央から左右へ 75px ずつ開く |
| f48–66 | 社名 | 不透明度 0→1、15px 下から上がる |

- 構成: 中央の1点から開く。開ききってから名前が出る。
- 再現判定: ◎

### B3 ロゴのグリッチ(`logo-glitch-reveal.tsx`)

| 時刻 | 要素 | 動き |
|---|---|---|
| f0–30 | 赤、緑、青の3枚に分けたロゴ | それぞれ横 ±15px、縦 ±10px で揺れる。揺れ幅は30フレームかけて0へ減る |
| f20–35 | 3色の層 | 不透明度 0.7→0 |
| f25〜 | 正しいロゴ | 不透明度 0→1。spring(damping 14, stiffness 80, mass 0.6) |
| f20–40 | ロゴの光彩 | 0→1 |

- 構成: 揺れは乱数ではなく、周期の違う sin で作る(係数 3.9〜11.7)。何度書き出しても同じ結果になる。
- 再現判定: ◎

### B4 レターボックス(`letterbox-reveal.tsx`)

| 時刻 | 要素 | 動き |
|---|---|---|
| f0–60 | 上下の黒帯 | 高さ 50%→12%。直線補間 |
| f15–45 | 中央の文字(64px) | 不透明度 0→1 |

- 構成: 画面全体が黒から始まり、帯が開いて映画の画角になる。帯は最後まで残る。
- 再現判定: ◎

### B5 名前テロップ(`lower-third.tsx`)

| 時刻 | 要素 | 動き |
|---|---|---|
| f0–25 | アクセントの細い帯 | 左 300px 外から入る。spring(damping 15, mass 0.6) |
| f5–35 | 名前の入る帯 | 左 400px 外から入る。spring(damping 14, mass 0.7) |
| f15–35 | 名前(約26px)と肩書き(16px) | 不透明度 0→1 |

- 構成: 帯、帯、文字の順に5〜10フレームずらす。行き過ぎないばね(damping 14〜15)で落ち着いた印象にする。
- 再現判定: ◎

### 補足 クレジットロール(`credits-roll.tsx`)

役職と名前の組を縦に並べ、1フレームあたり 1.5px の一定速度で上へ流す。画面の下端の外から始まる。ED で使う。再現判定: ◎

## 共通パターン

1. 動きは一方向で、1つずつ順に起きる。同時に動く要素は2つまで。
2. ばねは damping 14〜15 で行き過ぎを抑える。YouTube系(damping 8〜12)より硬い。
3. ロゴ、社名、タグラインの順に出す。それぞれ 0.5 秒前後の間を置く。
4. 色は地、文字、アクセントの3色。
5. 2〜2.5秒で動きが終わる。残りは静止か、ごく小さな変化だけ。

## 試作仕様 CORP-OPENER(8秒、240フレーム)

実装: `src/compositions/corporate/CorpOpener.tsx`

社名「ハクト製作所」とマークは仮のもの。サンプルは暗い地が多いので、明るい地に濃い緑を1色だけ置いた。

| 時刻 | 要素 | 動き | 元にしたサンプル |
|---|---|---|---|
| f0–24 | 上下の黒帯 | 高さ 50%→0。inOut | B4 |
| f8–50 | 細い罫線4本 | 四隅から伸びて枠になる。inOut | 新規 |
| f16–56 | マークの外形(角丸の四角) | 線で描く。inOut | B1 |
| f30–66 | マークの内側(右上がりの折れ線) | 14フレーム遅れて線で描く | B1 |
| f60–80 | マークの塗り(緑) | 不透明度 0→1。同時に外形の線が消え、折れ線が白に変わる | B1 |
| f62–78 | 折れ線の先の点 | 拡大して現れる。back | 新規 |
| f76–104 | マーク | 左へ 430px 移動し、1.35倍から等倍へ。inOut | B2 |
| f84〜 | 社名(132px) | 1文字ずつ下からせり上がる。3フレーム間隔、1文字20フレーム | B2 |
| f100–118 | 英字の社名(34px、字間 0.42em) | 不透明度 0→1 | B1 |
| f108–136 | 短い罫線(緑) | 中央から 220px まで伸びる | 新規 |
| f118–140 | タグライン(明朝、44px) | 18px 下から上がる。字間が 0.6em から 0.32em へ締まる | 新規 |
| f150–180 | 光の帯 | マークの上を左から右へ1回横切る | 新規 |
| f0–240 | 全体 | 1→1.03倍にゆっくり寄る | 新規 |
| f210–236 | 上下の黒帯 | 高さ 0→50% で閉じる | B4 |

差し替えできる項目: 社名、英字の社名、タグライン、3色。マークの形は `MARK_OUTER` と `MARK_LINE` の SVG パスを書き換える。

次に検討すること:

- 自社のロゴに差し替える。SVG のパスがあれば線描きにできる。画像しかない場合は B2(左右展開)か、ぼかしからの登場に切り替える。
- 同じ配色と書体で、名前テロップ(B5)と章の見出しを別のコンポジションとして追加する。
- 効果音を入れる(線描きに細い音、塗りに低い音)。
- 5秒の短縮版。
