# 02 アニメ風のOP

## ジャンルの前提

- テレビアニメの OP と ED は約90秒が標準。
- 曲を先に作ってから映像を編集するため、ショットの時間構造が音楽と密に対応する。本編より音との同期が厳密になる。
- テレビ用の短縮版では、Aメロ、Bメロ、サビの順が基本形。サビから始める形や、Aメロを2回置く形もある。
- スタッフのクレジットが必ず入る。文字を絵に重ねるだけの形と、画面の一部として動かす形がある。

## この章の根拠について

5本とも「文献」です。公開されている分析記事と論文から、数値と構造だけを取りました。この環境からは映像を視聴できないため、元の映像での確認はしていません。記事に書かれていない項目は「記載なし」としています。

配信で確認して `_template.md` を埋めれば「目視」に、権利のある動画を `scripts/analyze.sh` にかければ「動画実測」に置き換えられます。

Remotion は絵を描けないので、どのサンプルも作画の部分は再現の対象外です。判定は、構成、タイミング、文字、図形の部分についてのものです。

## サンプル仕様

### A1 長回し型(1974年のテレビシリーズ『アルプスの少女ハイジ』OP)

根拠: 早稲田大学リポジトリ掲載のショット分析(文献)

| 項目 | 内容 |
|---|---|
| 尺とショット数 | 約84秒、14ショット。平均は約6秒 |
| 配分 | 最初の2ショットで約20秒(全体の約4分の1)。題名は約20秒後、3ショット目の中で出る |
| ショット長 | 最短は約2.1秒(顔の寄り)。中盤に約4.2秒のショットが3つ続く。3ショット連続の場面は 3.4秒、2.2秒、5.1秒 |
| カメラ | 左パン、上へのティルト、横移動、寄り、固定。前半は移動、後半は固定が多い |
| つなぎ | ほぼカット。クロスディゾルブは3か所(冒頭と、同じ構図で季節だけ変わる場面) |
| 音との同期 | 4拍子の奇数拍で大きく、偶数拍で小さく動く。小節の区切りとカットをあえてずらし、数ショットを一続きに見せる箇所がある。最短ショットは歌の1語に合わせる |
| クレジット | 記載なし |

Remotion での再現:

| 要素 | 判定 | 方法 |
|---|---|---|
| ゆっくりしたパンとティルト | ◎ | 層ごとに移動量を変えた視差 |
| クロスディゾルブ | ◎ | `@remotion/transitions` の fade |
| 同じ構図で背景だけ差し替え | ◎ | 背景の層だけを切り替える |
| 人物の動き | × | 素材として用意して合成 |

### A2 高密度フラッシュ型(1995年のテレビシリーズ『新世紀エヴァンゲリオン』OP)

根拠: NEWREEL の連載記事(文献)。同じ作品について、早稲田の論文も「約90秒で90ショット以上」としている。

| 項目 | 内容 |
|---|---|
| 尺とショット数 | 90秒弱、89カット(記事の数え方)。平均は約1秒 |
| 配分 | 全体を3等分すると、最後の3分の1に68カットが集まる。前の3分の2は約21カット |
| 音との同期 | 切り替えを1拍目ではなく2拍目に置く。1拍目には閃光や背景の変化だけを置き、2拍目で主役や文字を出す |
| フラッシュカット | 16分音符のスネアに合わせて連打する。1枚は数フレームで、内容を読み取れない密度 |
| 文字 | 画面いっぱいの大きな文字カット。題名は白黒の中に薄く出し、2拍目で白黒反転して明示する |
| その他の同期 | ドラムのフィルに白黒の模様、和音の4拍に人物の出入り |
| クレジット | 記載なし |

Remotion での再現:

| 要素 | 判定 | 方法 |
|---|---|---|
| 拍に合わせたカット | ◎ | 拍をフレームに変換(`makeGrid`) |
| 2拍目へのずらし | ◎ | カットの開始拍を1つ後ろにする |
| 数フレームのフラッシュカット | ◎ | フレーム番号を3で割った商で絵を切り替える |
| 大きな文字カット、白黒反転 | ◎ | テキストと配色の切り替え |
| フラッシュに使う絵の素材 | × | 図形で代用するか、静止画を用意 |

### A3 既存素材の再構成型(2019年のテレビシリーズ OP、CGWORLD 掲載)

根拠: CGWORLD のメイキング記事の前篇(文献)

| 項目 | 内容 |
|---|---|
| 尺とショット数 | 記載なし。記事は7つのブロックに分けて解説 |
| 制作体制 | 1人で絵コンテから仕上げまで担当。新しい作画の発注はなし |
| 素材 | 提供された版権イラスト、設定画、本編のセル素材と背景を配置し直す |
| 質感 | テクスチャを重ねる。色を落とすか白黒にして、一部の色だけ残す |
| 3D | 題名ロゴを立体にして回転させる。雲、炎、破片は 3DCG で作って連番画像で合成 |
| つなぎ | 前後のブロックがつながるように組み、ワンカットのように見せる |
| 音との同期 | 歌詞との同期はあえてずらし、絵と歌の情報が重ならないようにする |
| 使用ツール | After Effects が中心。3D は Cinema 4D |

Remotion での再現:

| 要素 | 判定 | 方法 |
|---|---|---|
| 静止画の配置とカメラワーク | ◎ | 画像の層を移動、拡大、回転 |
| 白黒化と一部の色残し | ○ | CSS フィルターとマスク |
| テクスチャの重ね | ◎ | 合成モード、`Grain` 部品 |
| ワンカットに見えるつなぎ | ○ | 共通の層をまたいで動かす。設計に手間がかかる |
| 立体ロゴの回転 | ○ | `@remotion/three` |
| 炎、破片 | △ | 素材動画を重ねる |

このサンプルは、作画をせずに静止画と図形で OP を組む実例で、Remotion の試作に最も近い作り方です。

### A4 クレジット一体型(2015年のテレビシリーズ OP)

根拠: Medium の OP 論(文献)

| 項目 | 内容 |
|---|---|
| 尺とショット数 | 記載なし |
| クレジット | 最初のクレジットから最後まで、文字が画面を流れたり、階段などの物に沿って置かれたりする。絵の上に載せるのではなく、絵の一部になっている |

Remotion での再現:

| 要素 | 判定 | 方法 |
|---|---|---|
| 物の形に沿った文字 | ◎ | 位置と角度を図形に合わせる。曲線は SVG の textPath |
| 奥行きのある面に貼った文字 | ○ | CSS の 3D 変形 |
| クレジットの差し替え | ◎ | 役職と名前を配列で渡す |

### A5 構成の幅(1963年から現在までの比較)

根拠: 早稲田の論文中の比較と、楽曲構成を整理した記事(文献)

| 項目 | 内容 |
|---|---|
| ショット数の幅 | 7ショットの OP から、80秒で34ショット、約90秒で90ショット以上まである。平均ショット長は約12秒から約1秒まで開く |
| 曲の構成 | 約90秒の中で Aメロ、Bメロ、サビの3部が基本。サビ始まり、Aメロ2回などの変形がある |
| 各部の秒数 | 記載なし |

読み取れること: カットの速さに決まりはない。曲のテンポと作品の調子で決まる。試作では A1 の遅さと A2 の速さを、1本の中で前半と後半に分けて使う。

## 共通パターン

1. カットは拍か小節に合わせる。ただし頭の拍に全部を置かず、2拍目へずらす手法がある(A2)。区切りをまたぐ手法もある(A1)。
2. カットの密度は均等でない。静かな部分は長く、盛り上がりで細かくなる。
3. 題名は冒頭すぐではなく、少し待ってから出る(A1 は約20秒後)。
4. 文字は情報であると同時に絵の要素として使う(A2 の文字カット、A4 のクレジット)。
5. 作画なしでも、静止画、図形、文字、質感の重ねで成立する(A3)。

## 試作仕様 ANIME-OP(150 BPM、20小節、32秒、960フレーム)

実装: `src/compositions/anime/AnimeOP.tsx`、カット表の正本は `src/compositions/anime/cuts.ts`

- 標準の約90秒の3分の1の長さ。構成の検証が目的で、曲が決まったら小節数を増やす。
- 150 BPM、30fps では1拍が12フレーム、1小節が48フレームで、ずれが出ない。
- 題名「アオイ信号」、クレジットの名前、図形はすべて仮のもの。
- 人物の絵は入れていない。素材枠 A、B、C に画像を入れると表示される。
- 曲の代わりに拍のクリック音を入れている(`guideClick`)。

| カット | 小節.拍 | フレーム | 部分 | 内容 | カメラ | 元にしたサンプル |
|---|---|---|---|---|---|---|
| C01 | 1.1 | 0–48 | イントロ | 暗転。1拍目に白い閃光、2拍目から線が1本伸びる。クレジット1 | 固定 | A2(1拍目は閃光だけ) |
| C02 | 2.1 | 48–96 | イントロ | 白黒。輪郭だけの大きな英字が流れる。赤い点が拍ごとに点滅。クレジット2 | 文字が左へ | A2(白黒の中の薄い題名) |
| C03 | 3.1 | 96–192 | 題字 | 1拍目は地の色だけ変わる。2拍目に題名が1文字ずつ出る | ゆっくり寄る | A2(2拍目で明示) |
| C04 | 5.1 | 192–288 | Aパート | 地平線と電柱。素材枠 A。クレジット3は電線の高さに置く | 左パン、3層の視差 | A1、A4 |
| C05 | 7.1 | 288–384 | Aパート | 信号塔と雲。クレジット4は縦書き | 上へ移動 | A1、A4 |
| C06 | 9.1 | 384–480 | Aパート | 車窓の列。素材枠 B。クレジット5 | 窓が左へ流れる | A1 |
| C07 | 11.1 | 480–576 | Aパート | 信号の寄り。12小節目の2拍目に赤から青へ変わる。クレジット6 | 固定 | A1(固定)、A2(2拍目) |
| C08a、b | 13.1、13.3 | 576–624 | ビルド | 1語を画面いっぱいに。2拍ずつ2枚 | 固定 | A2(文字カット) |
| C09a〜d | 14.1〜14.4 | 624–672 | ビルド | 1語を画面いっぱいに。1拍ずつ4枚 | 固定 | A2 |
| C10 | 15.1 | 672–768 | サビ | 斜めの速度線。信号が拍で弾む。2拍目と4拍目に言葉。素材枠 C。クレジット7 | 固定 | A2(2拍目) |
| C11 | 17.1 | 768–816 | サビ | 図形のフラッシュカット。3フレームごとに16枚 | 固定 | A2(16分の連打) |
| C12 | 18.1 | 816–864 | サビ | 放射状の線が回る。青い円が画面を覆う | 回転 | 新規 |
| C13 | 19.1 | 864–960 | 締め | 題名に戻る。クレジット8。最後の12フレームで暗転 | 固定 | A1(最後は静止) |

構成の数値:

- カット数は32(C11 の16枚を含む)。最初の12小節に7、残りの8小節に25。後ろに密度を寄せた(A2 の配分)。
- A パートは1カット 3.2秒(A1 の中盤は約4.2秒)。
- 画面全体にフィルムグレインを2コマ打ちで重ねている(A3 の質感)。

差し替えできる項目: 題名と英字、文字カットの言葉8つ、クレジット8件、素材枠の画像3つ、クリック音の有無。

次に検討すること:

- 曲を決める。権利のある曲を `public/audio/` に置き、`scripts/analyze.sh` で BPM を測って `cuts.ts` の `ANIME_OP_BPM` を合わせる。
- 素材枠に入れるイラストを用意する。枠の寸法はコード中の各カットを参照。
- A パートのカット間にクロスディゾルブを入れる(A1)。
- C04 から C07 を共通の層でつなぎ、ワンカットに見せる(A3)。
- 89秒版への拡張。A パートとサビをそれぞれ2倍にする。
- ED 版。カットを減らし、縦スクロールのクレジットと1枚絵を中心にする。
